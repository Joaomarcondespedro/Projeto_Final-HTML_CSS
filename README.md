# Projeto Final - Landing Page (HTML & CSS)

Este projeto foi desenvolvido como trabalho final para a disciplina de **HTML e CSS** da faculdade. O objetivo do projeto foi aplicar os conceitos fundamentais de estruturação e estilização web para construir uma *landing page* completa.

> **Restrição do Projeto:** De acordo com os requisitos acadêmicos, foi permitido exclusivamente o uso de **HTML** e **CSS**, sem o auxílio de linguagens de script (como JavaScript) ou *frameworks* de terceiros.

---

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo e acessibilidade.
* **CSS3:** Estilização visual, layout (Flexbox e/ou Grid), responsividade e design da página.

---

## ✨ Destaques do Projeto

* **HTML Semântico:** Utilização correta de tags estruturais (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) para melhor organização e SEO.
* **Design Responsivo:** Adaptação da interface para diferentes tamanhos de tela (desktop, tablet e mobile).
* **CSS Puro:** Construção de layout, estilização, efeitos visuais e interações (como menus ou estados de *hover*) utilizando apenas recursos nativos do CSS.

---
